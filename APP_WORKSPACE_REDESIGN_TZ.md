# Техническое Задание и Руководство (LLM Prompt & Architecture Spec)
## Редизайн Рабочего Пространства /app (Sui Cleaner Workspace)

---

## 1. Проблема текущего интерфейса (Why It Needs a Complete Overhaul)

Текущий экран после сканирования кошелька выглядит как **сухая корпоративная админ-панель / Grafana Dashboard**:
1. **Скучная метрическая сетка**: Одинаковые плоские прямоугольники с цифрами (`295 TOTAL`, `31 REVIEW`, `44 CLEAN`, `3 PROTECTED`), напоминающие метрики серверов в облаке.
2. **Текстовые списки без жизни**: 6 безликих блоков со списками названий (`BLUB`, `DEEP`, `Unknown NFT x55`, `Suilend x2`). Нет визуальных превью NFT, нет логотипов протоколов, нет ощущения ценности или мусора.
3. **Плоские серые полосы действий**: «WHAT CAN YOU DO WITH THIS WALLET?» в виде серых кнопок-полос во всю ширину.
4. **Отсутствие атмосферы и погружения**: Окно модалки Connect Wallet уже выполнено в кинематографичном fantasy/crypto стиле, но при переходе внутрь пользователь попадает в темную пустую админку без глубины, магии очистки и осязаемой выгоды (Storage Rebate).

## 2. Новая Концепция: «Sui Cleaner Alchemist Vault & Cleaning Desk»

Вместо унылого «мониторинга объектов» интерфейс должен стать **Интерактивной Лабораторией Очистки и Инвентарем Кошелька**:
- **Осязаемая выгода (Storage Rebates)**: Пользователь видит кошелек как сокровищницу, засорённую «фантомными» пустыми объектами, за уничтожение которых блокчейн Sui **выплачивает реальные SUI (Storage Rebate)**.
- **Интерактивный Инвентарь (RPG / Cyber-Alchemist Inventory)**:
  - 🪙 **Токены**: яркие значки, балансы, стоимость в USD, статус (Ценный / Пыль).
  - 🖼 **NFT**: карточки с превью/изображениями, бейджи коллекций, предупреждения о спам/дрейнер NFT (`🚨 Suspicious`).
  - ⚡ **DeFi**: протокольные плашки с логотипами (Cetus, Navi, Scallop, Suilend, Aftermath), объем заблокированных средств.
  - 🗑 **Пустые монеты (Zero Coins)**: полупрозрачные, «расколотые» кристаллические артефакты с подписью: `+0.0028 SUI Rebate`.
- **Карточки Операций Очистки (Cleanup Quests)** вместо сухих полосок:
  - 🧹 **Операция: Утилизация 0-балансов** (*44 объекта → Возврат +0.088 SUI на баланс*).
  - 🌊 **Операция: Сбор пыли (Dust Sweep)** (*16 микро-токенов → Конвертация в SUI*).
  - 🛡 **Операция: Карантин подозрительных объектов** (*31 спам-предмет → Изоляция/Сжигание*).
- **Живая печь очистки (Rebate Crucible / Cleanup Queue)**:
  - Панель очереди справа показывает не просто список, а интерактивный тигель/алтарь: при выборе объектов они «влетают» искрами в тигель, где в реальном времени считается **Общий возврат SUI (Storage Rebate)**, газ и чистая прибыль.

## 4. Визуальные требования и Стилистика (Design Guidelines)

1. **Цветовая палитра и материалы**:
   - Фон: Глубокий космический индиго `#06090f` с мягкими акцентными градиентами (Cyan/Mint/Gold) и радиальным свечением.
   - Карточки: Glassmorphism `rgba(13, 20, 34, 0.75)` с тонкой рамкой `1px solid rgba(120, 200, 255, 0.15)` и мягкой тенью `0 8px 32px rgba(0, 0, 0, 0.4)`.
   - Акценты:
     - 🌟 **Золото (SUI Rebate / Главный CTA)**: `#ffc94f` (glow: `rgba(255, 201, 79, 0.35)`).
     - 🌿 **Мята (Cleanable / Safe)**: `#3df5c5` (glow: `rgba(61, 245, 197, 0.25)`).
     - 💎 **Лазурь (Assets / Tokens)**: `#38bdf8`.
     - 🔮 **Фиолетовый (DeFi / Protocols)**: `#a78bfa`.
     - 🚨 **Коралл/Янтарь (Review / Spam Warning)**: `#fb7185`.

2. **Типографика**:
   - Заголовки и крупные числа: `Space Grotesk` (современный, технологичный, четкий).
   - Основной текст, бейджи, кнопки: `Inter` (высокая читаемость, правильный letter-spacing).
   - Технические данные, хэши, Object ID, адреса: `JetBrains Mono` или `IBM Plex Mono`.
   - **Никаких пиксельных ретро-шрифтов** в основных элементах управления!

3. **Интерактивные микро-взаимодействия**:
   - При выборе объекта: плавная анимация обводки, галочка выбора, полет светящейся искры в правую панель очереди.
   - Hover карточек: мягкий подъем на `translateY(-3px)`, усиление неонового свечения рамки.
   - Пакетный выбор: «Выбрать все пустые монеты» с мгновенным пересчетом накопленного SUI Rebate.

## 5. Пошаговый План Реализации для Разработчика / LLM

### Шаг 1. Создание компонента шапки воркспейса (`VaultBanner.tsx`)
- Отображает:
  - Адрес кошелька с кнопкой копирования и иконкой эксплорера.
  - Сводку: Чистота кошелька, Общее число объектов, Количество пустых монет, **Суммарный Rebate**.
  - Быструю кнопку: «Quick Clean All Empty Coins».

### Шаг 2. Обновление навигации и фильтрации (`WorkspaceNavDock.tsx`)
- Преобразование левого меню в эргономичный верхний/боковой переключатель с живыми счетчиками:
  - `All Objects (295)`, `Tokens & Coins (5)`, `NFTs & Kiosks (55)`, `DeFi (2)`, `Zero Coins (44)`, `Needs Review (31)`.
- Добавление строки быстрого поиска (Search by name / 0x objectId) и сортировки (По балансу, по выгоде рибейта, по статусу).

### Шаг 3. Переработка сетки объектов в `CleanerDesk.tsx`
- **Замена скучных прямоугольников на интерактивные карточки**:
  - Карточки `TokenCard`: иконка токена, баланс, эквивалент USD, кнопка быстрого добавления в sweep/clean.
  - Карточки `NftCard`: превью изображения, имя коллекции, маркер верификации / предупреждение о спаме.
  - Карточки `ZeroCoinCard`: кристаллический полупрозрачный вид, плашка `+0.0028 SUI Rebate`, тумблер выбора.
  - Карточки `DefiPositionCard`: логотип протокола (Cetus, Suilend, Navi), тип позиции.
- Блок **«Action Quests»** (Интерактивные баннеры доступных улучшений вместо плоских полос).

### Шаг 4. Редизайн панели очереди (`QueuePanel.tsx`)
- Превращение правой панели в «Алтарь Рибейтов»:
  - Анимированный счетчик: `Reclaimable: +X.XXXX SUI`.
  - Список выбранных элементов с бейджами действий (`destroy_zero`, `burn`, `merge`).
  - Прозрачный калькулятор (Rebate, Network Gas, Net Profit).
  - Большая золотая кнопка `PROCEED TO CLEANUP →`.

### Шаг 5. Сохранение и проверка всей бизнес-логики
- **НЕ менять**:
  - Логику сканирования (`walletScanner.ts`, `objectClassifier.ts`).
  - Построение транзакций очистки (`cleanupEngine.ts`, `ptbBuilder.ts`).
  - Симуляцию и проверку безопасности (`dryRun`, `postTxVerifier.ts`).
  - Подключение кошельков (`@mysten/dapp-kit`).
- **Протестировать**:
  - Демо-режим (`/app?demo=true`).
  - Onchain-режим с реальным кошельком.
  - Read-only скан любого публичного адреса (`/app?scan=0x...`).
  - Полный цикл очистки: Выбор → Обзор → Симуляция → Подпись → Верификация.

## 6. Чеклист проверки результата (Acceptance Criteria)

- [ ] Страница `/app` больше не похожа на сухую админку или график мониторинга серверов.
- [ ] Визуальный стиль соответствует миру Sui Cleaner (стекло, неон, космический индиго, золото, интерактивность).
- [ ] Четко видна финансовая выгода: сколько SUI вернется пользователю через Storage Rebates.
- [ ] Все типы объектов (Токены, NFT, DeFi, Нулевые монеты, Спам) имеют свои уникальные информативные карточки с иконками.
- [ ] Поиск и фильтры работают мгновенно без перезагрузок.
- [ ] Анимации добавления в очередь и расчёт комиссии плавные и понятные.
- [ ] На смартфонах и планшетах интерфейс адаптируется в удобную одноколоночную мобильную версию.
- [ ] Все транзакции, симуляции dry-run и интеграция с Sui dApp Kit функционируют безошибочно.
